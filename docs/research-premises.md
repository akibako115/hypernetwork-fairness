## 研究の動機と新規性の置き所

- 事前に決めた demographic 属性の群だけで公平性を測ると、モデル内部にある別のバイアスが群の切り方に
  隠れる可能性がある。そこで、属性ではなく潜在空間で部分群を見る（LHCF と同じ問題意識）。
- 新規性は「hypernetwork・MoE による部分群ごとの推論」と「潜在空間で見る部分群」の組み合わせに置く。
- 目指す結果は、潜在空間で改善した結果として、最終評価の demographic 群でも改善が見えること。
  demographic の群差を直接縮めること自体は狙いではない（2026-10-08）。
- 潜在バイアスの監査だけをまとめる論文は、今の結果とは合うが新規性とインパクトが足りないと判断した（2026-10-09）。
- **軸は hypernetwork（属性条件付きの予測）に置く**（2026-10-13）。ラベルの意味の分解（`direction_poc` の方向 5）は
  主軸にしない。理由：属性条件付きの予測では MoE の論文は多いが、hypernetwork の先行研究は少なく、研究の余地が大きい。
  10-08〜10-12 は方針の決定も含めてエージェントに任せたところ、軸が定まらないまま分析と PoC が広がった。
  新しい実験は、この軸とどうつながるかを先に書いてから始める。

## 公平性のスコープ：動作点

- CheXpert の AUROC の年齢差は、ラベルの付け方の違いで説明できる。高齢の「No Finding」陽性には、正常を明言した
  レポートではなく、追跡撮影の質問に答えただけのレポートから付いたものが多い。陽性を正常明言のものに絞ると、
  差は 0.065 から 0.012 に縮む（`analysis/archive/direction_poc/reports/d5_label_semantics.md`）。HAM10000・FairVLMed でも
  AUROC の差は小さい。
- したがって、この研究で扱う公平性の問題は、主に群ごとの動作点（TPR・FPR）のずれとする（2026-10-12）。
- 動作点は**仮置き**の定義である。公平性の定義は先行研究でも分野全体でも定まっていないので、評価の仕方も含めて
  検討を続ける（2026-10-13）。
- val で決めた群別しきい値（後処理）は、動作点の公平性を取る最も単純な方法として**参考に置く**（2026-10-13）。
  Q2 では、公平性損失の効果は群別しきい値で代わりが利いた。ただし先行研究でこれを比較の基準にしたものはほとんど無く、
  上回ることを主張の条件にはしない。性能で勝負する方向なら参考の比較に入れ、属性ラベルの要否やアイデアの新規性を
  重視する方向なら重く扱わない（群別しきい値は推論時に属性ラベルを要する）。
- **主の評価は固定しきい値 0.5 で行う**（2026-10-13）。MoE・属性条件付きモデルの先行研究（FairAdaBN、FairMoE、
  Fair-MoE、FairCLIP の系統）が既定のしきい値か argmax で評価しているのに合わせる。臨床の用途に踏み込んだ分析
  （FPR を固定した点、群別しきい値の規則の比較など）は、発展的な分析として別に扱う。
  - 0.5 がどの動作点に当たるかは class weight で決まる。全手法で全群共通の inverse class weight にそろえる。
  - ERM に val で決めた群別しきい値を当てたものは、参考の 1 行として置く（主比較の基準にはしない）。
  - AUROC（全体・最悪群・gap）は、しきい値によらない指標として併記する。
- **評価する指標**（属性の群で求める。2026-10-13）
  - 動作点（固定しきい値 0.5）：Eopp1（群の TPR の最大 − 最小）、Eopp0（群の FPR の最大 − 最小）、Eodds（両者の平均）、
    害の大きい側の最悪群の率。全体の TPR・FPR も併記する。
  - 害の大きい側の最悪群の率は、差だけだと全群が悪くなって縮んだ場合も改善に見えるので並べる。向きはデータセットごとに決める。
    - CheXpert（No Finding、陽性＝所見なし）：最大の FPR。病変のある人を正常と判定した割合で、見落としに当たる
      （Seyyed-Kalantari et al., Nature Medicine 2021 の過小診断と同じ見方。書誌は使う前に原典で確認する）。
    - HAM10000（悪性を陽性とする 2 値）：最小の TPR。悪性の見落としに当たる。
    - FairVLMed（緑内障を陽性とする 2 値）：最小の TPR。緑内障の見落としに当たる。
    - 他のデータセットを足すときは、陽性の定義を見て同じ考えで決め、ここに書き足す。
  - しきい値によらない指標：全体 AUROC、最悪群 AUROC、AUROC gap（最大 − 最小）。
  - 率を出すセルの下限は 20 件（[data_pipeline/README.md](../data_pipeline/README.md)）。TPR は陽性の数、FPR は陰性の数で別々に判定する。
  - 区間は患者（皮膚は病変）単位の bootstrap 95%。
  - **評価できた群の数を併記する。** セルの下限で外れた群があると gap は小さく見える。手法の間で評価に残った群が
    違う場合は、その旨を書く。
  - **区間が何の揺れを表すかを結果表に明記する。** 患者（病変）の標本誤差だけか、学習の seed の揺れも含むかを書く。
    2 段の学習で 1 段目を固定して 2 段目の seed だけを振った反復は、手順全体の再現ではないので区別する
    （[20261013_experiment_project_review.md](reviews/20261013_experiment_project_review.md)）。
- **較正は崩してよい。** calibration fairness は王道の指標ではないので主指標にしない。TPR・FPR をそろえるために
  群ごとの較正がずれることは許容する（2026-10-12）。

## 手法の選び方

- 比較する公平性手法は、先行研究で提案済みのものを使う。原典を確認してから実装する（2026-09-29、2026-10-05）。
- ハイパーパラメータは原論文の値に合わせる（2026-10-10）。変えた場合は理由を報告と文書に残す。
- 公開実装が無いことは除外の理由にしない。論文の記述から再実装できるかで判断する
  （[fairness-baseline-methods.md](methods/fairness-baseline-methods.md)）。
- 手法ごとに独自の改良を足さない。例：class-balanced GroupDRO のような改変は、他の先行手法を入れるたびに
  同じ工夫を考えて検証することになるので採らない（2026-09-29）。
- 結果を成立させるための工学的な小技に頼らない。例：陽性が 30 件未満の潜在クラスタを近い群へ併合する案は却下した。
  群が少数で比較が成り立たない場合は、併合せずに「比較として成り立たない」と報告する（2026-10-10）。
- GroupDRO は q が最悪群に向かないことが分かっており、公平性手法の代表にしない。結論は複数の手法で支える（2026-10-09〜10）。

## class weight

- 分類損失の項にだけ、全群共通の inverse class weight を掛ける。
- 群ごとの class weight と、属性 × ラベルのセルで均等にする重み付けは使わない（2026-09-29〜30）。
  群ごとの class weight は群ごとにスコアの切片をずらし、全体 AUROC を下げた。
- 条件付き公平性項には CE の class weight を掛けない（[fairness-objective-alternatives.md](methods/fairness-objective-alternatives.md)）。

## データセットの役割

- 主軸は CheXpert とする。HAM10000・FairVLMed は「胸部 X 線だけでうまくいかないのでは」を確かめる補足実験に使う。
  明確な理由なく、実験ごとにデータセットを変えない（2026-10-11）。
- 加工したデータ（偏りの植え込みなど）で出した結論は、必ず元データの結果と並べて示す。加工データだけの結果は
  「加工データでしか言えない」結論になる（2026-10-11）。
- 年齢は 65 歳で 2 区分にする。CheXpert の属性群は年齢 × race（White / Asian / Black / Others）の 8 群、HAM10000 は性別 × 年齢の 4 群
  （定義の正本は [20261002_experiment.md](plans/20261002_experiment.md) と各分析 package）。

### 皮膚画像：HAM10000 と ISIC 2019（2026-10-12）

HAM10000 の本体 10,015 枚は ISIC 2019 Training にすべて含まれる（ISIC 2019 の `attribution` が HAM10000 の群）。
HAM10000 の公式 test（ISIC2018 Task3）は、どちらの本体とも重ならない。

- **皮膚画像の補足実験は HAM10000 にそろえる。** split は `data/ham10000/splits*`、test は公式 test を使う。
  Q1〜Q3 のどれでも、皮膚画像の補足はまず HAM10000 で行う。
- **ISIC 2019 は、複数施設が要る問いにだけ使う。** 用途は BCN20000 で学習して HAM10000 の部分に展開する施設間の
  設定に限り、「植え込みではない実際のずれでも同じことが言えるか」を示す付録として扱う。
  病変単位でランダムに分けた `data/isic2019/splits_fairness/` と 5-fold CV は、新しい実験では使わない。
- **2 つを混ぜない。**
  - HAM10000 の split で学習・fit したもの（モデル、埋め込みの GMM・k-means、監査器、しきい値）を ISIC 2019 の
    データに当てない。逆も同じ。本体が重なり病変の分け方も違うので、train の画像が評価側に入る。
  - cache と split の名前は `isic_*` の接頭辞で分ける。
  - 報告では「HAM10000（公式 test）」と「ISIC 2019（BCN→HAM の施設間）」を書き分ける。施設間の評価 split
    （`isic_test`）は HAM10000 本体から作ったもので、公式 test ではない。target も違う
    （HAM10000 は mel・akiec を悪性とする 2 値、施設間はメラノーマの 2 値）。
