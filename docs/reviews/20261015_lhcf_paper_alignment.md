# LHCF の比較手法（FIS・FaMI）を論文に合わせた記録

2026-10-15。LHCF（Masroor et al., arXiv 2605.29827）の再現で使う FIS と FaMI を、論文の式どおりに直した。
独自の近似が原因でうまく動かない可能性を除くためである。学習は回していない。

**方針**：論文の式に従う。論文に書いていない所は公式実装に従い、公式実装もない所だけをこちらで決めて、その旨を書く。

## 修正の影響

- 修正前の FIS・FaMI の run（`analysis/archive/latent_bias_hypernet` の `fg_fis_*`・`fg_fami_*`）は、論文の手法の結果として読めない。
  FIS は 10-13 の修正（公式実装の正規化）の前後どちらの run も同じ扱いになる。
- ℓ_wst と潜在群（`splits_lhcf`）は変えていない。

## FIS（`objectives/cohort.py` の `FISTaskLoss`）

| 項目 | 修正前 | 修正後 | 根拠 |
| --- | --- | --- | --- |
| 比較相手 B^t_a | バッチ内の群 a の部分集合 | train の群 a から別に引いたミニバッチ（群あたり 64 件、毎 step） | 論文 Eq. 5 の定義。件数は公式実装の既定 |
| OT の相手 | バッチ全体と群 a の部分集合 | バッチ B^t の損失と B^t_a の損失 | 論文 Eq. 5。公式実装は B^t_a と全群の B^t_a の連結で、論文と違う |
| s^G の softmax | バッチの標本について（10-13 に公式実装に合わせた） | 群について（和が 1） | 論文 Eq. 5 |
| Sinkhorn の blur | 0.05 | 0.1 | 論文に記載なし。公式実装の既定 |
| 勾配 | s^I・s^G とも流さない | s^I には流し、s^G には流さない | 論文に記載なし。公式実装は s^I を detach せず、s^G は勾配なしの B^t_a から作る |

- 論文の形では、s^G_{a_i} が 1/|A| 前後、s^I_i が 1/|B| 前後になる。c = 0.5 でも群の項がずっと大きい（11 群・バッチ 128 なら約 12 倍）。
  10-13 の修正はこれを「c が混合比として働かない不具合」として公式実装の形に直したが、論文の式はこの形である。
- B^t_a は `GroupImageDataModule.group_sample_batches` が作り、`LitModule` が毎 step、train モード・勾配なしで forward する（公式実装と同じ）。
  BatchNorm の統計は B^t_a でも動く。1 step あたり、学習バッチのほかに 群数 × 64 枚（HAM10000 の潜在群なら 704 枚）の forward が増える。

## FaMI（`objectives/cohort.py` の `FaMITaskLoss`）

正本は Sadri et al. *Mutual Information Regularization for Fairness-aware Deep Imaging Representations*（MICCAI 2025）。
LHCF の文献 [34] は FairDomain（Tian et al., ECCV 2024）を指しているが、LHCF の本文の説明（相互情報量で表現と属性の依存を減らす）と
名前は Sadri et al. のものなので、引用の誤りと判断した。公式コードは公開されていない。

| 項目 | 修正前 | 修正後 | 根拠 |
| --- | --- | --- | --- |
| v | 2 クラスの logit 差（1 次元） | logits（2 次元） | Alg. 1 の v_i = f_θ(x_i)、p_i = softmax(v_i) |
| スコアの推定 | ガウス KDE（Silverman の幅） | 多項式の最小二乗スコア推定（各次元 3 次・交差項なし・正則化なし） | 論文は Babaie-Zadeh & Jutten 2005 の多項式推定を引く。基底は同論文の式 (29)–(35) |
| λ(u, v) | 群の条件付きスコア − 周辺スコア | 同じ | ∇_v ln p(u|v) = ∇_v ln p(v|u) − ∇_v ln p(v)。u が離散なので、この分解はこちらで選んだ |

- 論文に記載がなくこちらで決めたもの：基底の数（1 + 3·クラス数 = 7）より件数の少ない群の λ を 0 にする。係数は擬似逆行列で解く。
- μ = 0.5 は論文の値。論文の学習条件（SGD、勾配クリップ 1.0）は手法間でそろえるため使っていない。

## LHCF の潜在群（変えていない）

- 論文は ERM で学習した ResNet-18 の埋め込みに全共分散の GMM を当て、BIC で K = 7 を得ている。次元の扱い・K の探索範囲・
  val と test への割り当て方は書かれていない。付録もコードもない。
- こちらは比較の基準と同じ ResNet-50 ERM の埋め込みを使う（論文の枠組みでは、学習するモデル自身の encoder で群を作る）。
  2048 次元に全共分散の GMM は当てられないので、標準化して PCA 32 次元に落としている（論文に記載なし）。
- K の探索範囲を 2〜12 から広げて確かめた。K = 13 で BIC が上がり（1,375,270 > K = 11 の 1,373,660）、K ≥ 14 は成分がつぶれて当てられない。
  K = 11 のままでよい。

## テスト

`projects/hypernet_e2e/tests/test_cohort_objectives.py`：FIS の Eq. 3–5、群の重みの和、勾配の流れ方、群別の抽出、
Lightning の学習ループから B^t_a が渡ること、多項式推定がガウス分布のスコアを再現すること、FaMI の罰則の向き。
project のテストは全件通過。HAM10000 の実データで、潜在群 11 個から 64 件ずつ引けることを確かめた。
