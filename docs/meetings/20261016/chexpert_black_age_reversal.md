# CheXpert：Black で高齢群の性能が高く見える理由と、No Finding ラベルの年齢依存

ResNet-50 ERM（M01、global inverse class weight、3 seed）。target は No Finding の2値（陽性＝所見なし）。split は `splits_race_known`。
数値は best val AUROC checkpoint の AUROC で、3 seed の logit 平均から求めた。[ ] は患者単位 bootstrap の 95%区間。

## 事実

1. **test では Black だけ年齢の向きが逆になる。**

   | 群 | <65 | ≥65 |
   |---|---|---|
   | White | 0.884（陽性823） | 0.815（陽性365） |
   | Black | 0.836（陽性126） | 0.880（陽性22・13患者） |

   - 逆転は3 seedすべてで起きる。ただし3 seedは同じ test 患者で評価しているので、独立な再現ではない。
   - Black の差（≥65 − <65）は +0.045 [−0.04, +0.13] で、区間が0を含む。
2. **患者が重ならない val と train では逆転しない。**
   - val：Black <65 は 0.877、≥65 は 0.809（陽性34）。
   - train：Black <65 は 0.900、≥65 は 0.864。
3. **test の Black ≥65 は、陽性の構成が他の集合と違う。**

   | ≥65 の陽性に占める割合 | Black（test） | White（test） | Black（val） |
   |---|---|---|---|
   | 追跡撮影型のレポート | 41% | 61% | 62% |
   | AP撮影 | 45% | 66% | 71% |

   - 追跡撮影型とは、正常の明言がなく、デバイス・気胸・前回比較にだけ触れる impression を指す（`label_construct.py` の正規表現で分類）。
   - White ≥65 の構成を Black ≥65 に合わせて重み付けし直すと、AUROC は 0.815 から 0.860 に上がる。合わせた項目は年齢帯・撮影方向・BMI・初回か追跡か・性別・陽性のレポート種別。年齢だけで合わせた場合は 0.816 で、ほぼ動かない。
   - 陽性側の誤順位の 68% は、上位3患者から来ている。
4. **test の Black <65 が低いことは、構成では説明できない。**
   - White <65 を Black <65 の構成に合わせて重み付けし直すと 0.890 になり、低くならない。
   - 追跡撮影型の陽性に限った AUROC は 0.749 で、White <65 は 0.830。正常明言型に限ると 0.923 と 0.933 で、ほぼ同じ。
   - 陽性3患者と陰性3患者を除くと、0.836 が 0.870 になる。
5. **No Finding=1 の画像では、12病変のどれにも present も uncertain も付いていない。** train・val・test の陽性 20,278件を、HF の CheXpert v1.0 ラベル（`danjacobellis/chexpert`）と照合した。
   - 12病変は Support Devices を除く所見。No Finding は「どの病変にも陽性または疑いの言及がない」ときに付く。
   - 追跡撮影型の陽性では、Support Devices が present の例が約53%、Pneumothorax が absent の例が約71% あった。それ以外の病変は大半が blank（言及なし）だった。
6. **高齢ほど、absent と明記された病変が少ない。**

   | 年齢 | absent と明記された病変の数（平均） | 0個、または Pneumothorax だけの割合 |
   |---|---|---|
   | <50 | 2.75 | 18% |
   | 50–64 | 2.49 | 22% |
   | 65–79 | 2.17 | 32% |
   | 80+ | 1.83 | 35% |

   この傾向は、追跡撮影型（2.19 → 1.60）と正常明言型（3.27 → 2.61）のどちらでも見られる。

## 考察

- **陽性数十件規模の交差群の点推定は、患者構成の偶然で順位が入れ替わりうる。** 群間の比較には患者単位の区間を付けるか、別の患者集合で再現を確かめる必要がある。
- **群間の性能差には、群ごとのラベルの付き方の違いが混ざりうる。** ラベルの付き方とは、撮影の文脈やレポートの書かれ方を指す。構成をそろえた比較を行えば、この影響を分けられる。
- **No Finding は「正常と確認された」ではなく「病変に陽性の言及がない」を意味する。** 否定された病変の数が年齢で変わるので、ラベルの意味そのものが群によって異なる。この場合、群間の性能差には画像の判別しにくさとラベル定義の差の両方が含まれる。
- **未確認の点。** 高齢の陽性画像に、レポートが触れていない異常が実際に写っているかは、画像を確認していないので分からない。ラベル定義が年齢差にどの程度寄与しているかも、まだ量っていない。
