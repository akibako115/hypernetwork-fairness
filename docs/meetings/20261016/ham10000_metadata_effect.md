# HAM10000：メタデータ条件付けモデルの改善の内訳

ResNet-50・Spatial LoRA・HyperAdapt（e2e ERM、各3 seed）。target は mel+akiec を悪性とする2値。入力属性は性別・年齢・部位。
数値は test AUROC の3 seed平均。[ ] は病変単位の paired bootstrap 95%区間。

## 事実

1. **val では差が無く、test でだけ差が出る。**
   - val：ResNet 0.929、Spatial LoRA 0.934、HyperAdapt 0.934。
   - test 全1,511件：ResNet 0.894、Spatial LoRA 0.910、HyperAdapt 0.900。
   - val は本体のランダム分割、test は ISIC2018 公式 test で、新施設（external）を含む。
2. **改善は「黒色腫と、母斑以外の良性病変の区別」に集中する。**
   - 黒色腫 vs bkl は ResNet 0.799、Spatial LoRA 0.859、HyperAdapt 0.848。
   - 性別・年齢の群間差（gap・Eopp・Eodds）は変わらない。
3. **推論時の属性を全行同じ値に固定すると、改善の一部だけが消える**（既存施設の行、Spatial LoRA の ResNet 比）。

   | 区別する組 | 元の属性での差 | 属性を固定したときの差 |
   |---|---|---|
   | 黒色腫 vs 母斑 | +0.021 | +0.004 |
   | 黒色腫 vs bkl | +0.065 | +0.055 [+0.029, +0.082] |
   | 黒色腫 vs bcc | +0.071 | +0.070 [+0.034, +0.110] |

   - メタデータだけのモデルの区別力は、母斑 0.82、bkl 0.51、bcc 0.43。
   - ResNet にメタデータを後段結合すると、母斑だけ 0.927 → 0.940 と改善し、bkl・bcc は改善しない。
4. **external では条件付けモデルが ResNet を下回る**（ResNet 0.846、Spatial LoRA 0.822、HyperAdapt 0.799）。
   - 欠損年齢は 0歳として入り、標準化後に約 -3 SD になる。この値は train には現れない。
   - 年齢を train 平均で埋めると 0.871・0.858 に戻り、ResNet を上回る。

## 考察

- **ResNet は既存施設の新しい病変で、母斑以外の良性病変との区別を汎化できていない。**
  val ではこの弱さが表に出ず、test で bkl・bcc を相手にしたときに現れる。
- **黒色腫 vs 母斑の改善は、年齢などの事前確率で説明できる。** 母斑は若年に多いので、画像の外の情報として効く。
  後段結合でも同じ改善が得られるので、条件付けの仕組みである必要は無い。
- **黒色腫 vs bkl・bcc の改善は、画像側の表現の違いから来ている。**
  - メタデータだけではこれらを区別できない（bkl・bcc は黒色腫と年齢・部位が近い）。
  - 推論時に属性を固定しても改善が残る。
  - したがって条件付けモデルは、学習の結果として、ResNet よりこれらの病変の形態をよく区別する表現を持っている。
  - この差が adapter を足した構成によるのか、属性と一緒に学習したことによるのかは、今回の結果からは決まらない。
- **改善は群によらず一様で、公平性は動かない。** 属性は群ごとの補正としてではなく、全体の事前確率や表現学習の補助として効いている。
- **external での劣化と seed 間のばらつきの大部分は、欠損年齢を 0歳として符号化したことによる。** モデル本来の弱さではない。
  年齢を埋めれば新施設でも ResNet を上回るので、条件付けモデルの表現は新施設にも汎化している。
- **モデルは属性に依存している。** 属性を行間で入れ替えると、全行を固定した場合より悪くなる。
  誤った属性や学習分布の外の属性値は、そのまま性能低下につながる。
