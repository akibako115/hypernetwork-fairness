# 5 空間 × 群の作り方の比較と、小さな部分集団

[02 notebook](../02_space_comparison.ipynb) と [03 notebook](../03_calibration_bias.ipynb) の観察記録。2026-10-13。

- 対象：01 と同じ。CheXpert race-known の 1 段・ERM の Spatial LoRA、seed 42・43・44、best val AUROC
- 空間：属性（one-hot ＋ 年齢）、metadata encoder の c、生成 ΔW（3 stage の和）、モデル自身の特徴（head 直前、PCA 32・64）、RAD-DINO（PCA 32・64）
- 群の作り方
  - クラスタリング：k-means（K = 8）、GEORGE（クラスごとの GMM）、LHCF（GMM、K は BIC で選び、特徴 12・RAD-DINO 11）
  - 監査器：ridge（予測の分位で 8 群）、回帰木（葉の最小件数 500）
- 群はすべて val で作り、test で測る
- 表：`results/02_space_comparison/`、`results/03_calibration_bias/`
- 図：`figures/02_space_comparison/granularity_sweep.png`、`figures/03_calibration_bias/granularity_sweep.png`

物差しは 2 つ使った。

- **02**：しきい値 0.5 の FPR（見落とし）。監査器は、陰性で見落としたかどうかを予測する
- **03**：得点をそろえたうえでの陽性数の O/E（較正のずれ）。val 全体で、logit 差の 3 次スプラインのロジスティック回帰で再較正した確率に対して数える。監査器は残差 y − p を予測する（Kim et al. の形）。
  - log O/E < 0 は、その群でモデルが No Finding の確率を実際より高く出していることを表す。確率の上のずれであり、0.5 の見落とし（FPR）が多いことは意味しない
  - multiaccuracy が抑える量そのものは平均残差 (O − E)/n（差）で、log O/E（比）は要約として選んだもの。両方で群を選んで比べた（観察 4）
  - 較正のずれは性能の gap ではない。見つけた群の FPR・TPR・AUROC と補集合との差を別に測った（観察 4、`chosen_group_performance.csv`）

- RAD-DINO の監査器の群は、seed ごとの test の log O/E が −0.37・−0.48・−0.17 で、3 seed とも負だった。
- この群の構成は seed をまたいでよく似ている（全体に対する割合の比）。
  - 多い：気胸 1.35〜1.85 倍、胸骨切開 1.31〜1.37 倍、縦隔拡大 1.20〜1.37 倍、肺腫瘤 1.13〜1.35 倍

- ただし群そのものは seed で入れ替わる（test の ARI 0.12）。
- c / k-means の O/E 最小の群は「AP の正面像（側面・PA を含まない）」で、デバイス・中心静脈・気胸が多く、Black・Asian が少ない（比 0.47・0.63）。
- RAD-DINO / LHCF は、O/E のばらつきは帰無分布を超える（p = 0.005）。しかし val で選んだ群（胸骨切開 4.4 倍、中心静脈 1.9 倍）は test で再現しなかった（O/E 0.98）。

### 4. 較正のずれで選んだ群は、主指標の性能では悪くない（03 の 5 節）

val で選んだ群の test の性能と、補集合との差（gap = 群 − 補集合）。3 seed 平均。全体は FPR 0.246、AUROC 0.86 前後。

| 群（log O/E 最小で選択） | 件数 | 陽性率 | FPR（補集合） | gap FPR | gap TPR | gap AUROC | log O/E |
|---|---|---|---|---|---|---|---|
| 8 群 | 948 | 0.11 | 0.28（0.25） | +0.04 | −0.04 | −0.02 | −0.08 |
| c / k-means | 2,867 | 0.09 | 0.24（0.25） | −0.01 | +0.01 | −0.00 | −0.13 |
| ΔW / k-means | 3,174 | 0.11 | 0.28（0.25） | +0.03 | +0.04 | −0.00 | −0.06 |
| 特徴 / 監査器（ridge） | 2,461 | 0.13 | 0.38（0.23） | +0.15 | +0.10 | −0.01 | −0.17 |
| **RAD-DINO / 監査器（ridge）** | 2,306 | 0.05 | **0.18（0.26）** | **−0.07** | **−0.19** | −0.05 | −0.34 |

- **RAD-DINO の監査器の群は、FPR が補集合より低い**（gap −0.03・−0.13・−0.06）。陽性率が低く得点が全体に低い群なので、確率を高めに出しても 0.5 を超えない。この群で増えているのは見落としではなく、**正常な画像を所見ありと出す誤り**（TPR の gap −0.19）である。AUROC は 3 seed とも補集合よりやや低い（−0.04〜−0.06）が、得点の低い側に偏った群なので、得点の幅が狭いことによる低下を含む。
- **群をまたぐと、較正のずれと FPR は逆向きに並ぶ。** 各分割の群で log O/E と FPR の Spearman 相関は、RAD-DINO の監査器で +0.74、c・ΔW の k-means で +0.21・+0.28 だった（`calibration_vs_performance.csv`）。O/E が低い（確率を高めに出している）群ほど FPR は低い。8 群だけが −0.44 だった。
- **平均残差（差）で選ぶと、選ばれる群が変わる。** 2 つの選び方が同じ群を選んだのは、RAD-DINO の監査器で 3 seed 中 2、他の多くの分割では 0〜1 だった。
  - 差で選ぶと、陽性率と得点の高い群が選ばれやすい。その群は FPR も高い（特徴 / LHCF で gap +0.60、特徴 / 木で +0.57）。比で選ぶと逆に、得点の低い群が選ばれやすい。どちらの選び方も、選ばれる群の FPR は得点の水準でほぼ決まる。
  - RAD-DINO の監査器を差で選ぶと、seed 43 では別の群（log O/E −0.00）になり、3 seed 平均の log O/E は −0.34 から −0.18 に縮む。O/E 0.71 という大きさは、比で選んだことに一部依存している。
- k 近傍の球でも同じだった（`knn_ball_performance.csv`）。RAD-DINO の k = 1000 の球は FPR 0.21（補集合 0.25）、TPR の gap −0.17。c の球は FPR の gap +0.06〜+0.10 と小さい。特徴の k ≤ 200 の球は、残差で選んでも FPR 1.0 の高得点の領域になった。

## 解釈候補

- **群を探す目的を「しきい値での FPR」にすると、画像を見る空間では、群ではなく難しい画像を集めてしまう。** FPR は得点の関数なので、得点を予測できる空間ならいくらでも悪い群を作れる（観察 1）。柱 B で画像側の空間を使うなら、探す対象は「得点をそろえたうえでのずれ」（較正の O/E、multiaccuracy の残差）にする必要がある。評価の主指標（0.5 の FPR）は、群を作ったあとの報告に使うのが筋になる。
- **当初案（c・ΔW）が捉えるずれは、得点をそろえると小さい（O/E 0.88〜0.94）。** 01 で見た大きな FPR の差は、ほとんどが陽性率の違いからくる動作点の差だった。群ごとの切片の補正で直せる分は 1 割前後にとどまる。
- **属性で書けない較正のずれは、画像側の空間の監査器で見つかる。ただし、それは性能の gap ではない。** RAD-DINO の残差の監査器が見つけた群（O/E 0.71、約 2,300 枚）は属性ではほとんど決まらず、中身は気胸・胸骨切開・縦隔拡大の陰性に寄っている。推論 1（当初案は属性で書けないずれを原理的に拾えない）の裏返しの証拠にはなる。一方、この群の FPR は補集合より低く、主指標の上では悪い群ではない（観察 4）。モデルはこの群の No Finding の確率を高めに出すが、得点が低いので見落としにはつながらない。この群を「見落としの多い潜在群」と書くことはできない。
- **較正のずれ（multiaccuracy）と、しきい値での性能の gap は、別の量として扱う必要がある。** 群をまたぐと両者は逆向きに並ぶことが多い（観察 4）。multiaccuracy は期待値の上の正しさで、群の性能を保証しない。差で選ぶか比で選ぶかでも、選ばれる群の得点の水準が変わり、FPR はそれでほぼ決まる。柱 B の「捕捉」を性能の gap で問うなら、得点で自明にならず、かつ性能で測る発見の目的がまだ無い。
- **小さな部分集団は、データの量で見つけられる下限が決まっている。** val（陽性約 2,000）で群を作ると、期待陽性数が数十（画像で数百枚）より小さい群では、val で見えたずれの大半が選んだことによる偏り（勝者の呪い）で、test で再現するかは設定しだいになる。k 近傍の走査で有意になるのも 500 件以上の球だけだった。クラスタリングでも監査器でも同じ傾向である。「クラスタリングだと小さい箇所が見つからない」のは、手法より先に標本の大きさの問題である。

## 小さな部分集団に向けた方向

観察 3 から、手法の選び方より先に次の 2 つが効くと考える。

1. **発見に使うデータを大きくする。** train（約 16 万枚）を患者単位で分け、片方で学習したモデルの予測をもう片方で監査する（cross-fit）。陽性の数は val の 8 倍近くになり、検出できる群の下限が下がる。`data/chexpert/splits_crossfit/` と `latent_bias_hypernet` の 1 段目（A で学習）がそのまま使える。
2. **探す候補を絞って、多重比較を減らす。** 走査や木は候補が多く、帰無分布が広がる。報告書由来の要因（気胸・術後・デバイス）や撮影の条件のように、事前に意味のある候補へ絞れば、同じデータ量でも小さな群まで検定できる。ただし属性や要因で絞ると、属性で書けないずれは落ちる。画像空間の監査器で候補を出し、要因で解釈する、という 2 段の組み合わせが現実的と考える。

## 追加で確かめること

- RAD-DINO の監査器の群が、cross-fit の train でも同じ中身で出るか（seed 間の ARI が 0.12 と低く、群の境界は不安定）。
- 群ごとの補正（hypernetwork の条件付けや切片の補正）で O/E を戻すと、その群では確率が下がる。FPR はさらに下がり、TPR はさらに下がる可能性がある。O/E を戻すことを「改善」と呼べるかは、主指標との関係を決めてからになる。
- 性能の gap を目的にした発見（たとえば得点の層の中で FPR を比べる、AUROC の群間差を目的にする）を、得点で自明にならない形で作れるか。
- 正常を明言するレポートの陰性（01 の最悪 FPR 群に多い）のラベルの扱い。
- 再較正は val で当てている。群も val で作るので、val での O/E は較正の当てはめの分だけ 0 に寄る。test の値で読む。
- 監査器の正則化（ridge の α = 10）と、PCA の次元（64）は振っていない。
