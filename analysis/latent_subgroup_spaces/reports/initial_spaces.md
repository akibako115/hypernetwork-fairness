# 当初案（metadata encoder の空間・生成 ΔW の空間）で見つかる群

[01 notebook](../01_initial_spaces.ipynb) の観察記録。2026-10-13。

- 対象：CheXpert race-known、1 段・ERM の Spatial LoRA（stage3・stage4・fc を変調）、seed 42・43・44、best val AUROC の checkpoint
- 空間：metadata encoder の出力 c（16 次元）と、生成 ΔW（stage3・stage4・fc と 3 つの和）。ΔW は Gram 行列の重み付き kernel PCA の座標
- 群：k-means（K = 2〜8）を val の行に当て、test に同じ中心を当てる
- 物差し：しきい値 0.5 の FPR（所見のある画像を「所見なし」と出す見落とし）。群は val で作り、test で測る。帰無分布は群の大きさを保って陰性の見落としを並べ替えたときの最悪 FPR
- 表：`results/01_initial_spaces/`、図：`figures/01_initial_spaces/prevalence_vs_fpr.png`

## 観察事実

1. **モデルの動作点は seed で大きく違う。** test の全体 FPR は 0.304・0.207・0.229、TPR は 0.870・0.798・0.823（inverse class weight で学習し、しきい値 0.5 で切っている）。以下の FPR の比較は seed ごとに作り、3 seed の平均で示す。

2. **空間を決めているのは、単独の属性よりも属性の組み合わせである。** 属性 1 つで説明される分散（R²、`attribute_r2.csv`）は次のとおり。
   - c：年齢（5 歳刻み）0.36、race 0.18、ほかは 0.08〜0.10
   - ΔW：race 0.12、年齢 0.10、ほかは 0.04〜0.05
   - c は年齢の比重が大きく、ΔW は単独の属性ではほとんど説明できない（交互作用で決まる）。

3. **クラスタの最悪 FPR は 8 群より悪く、帰無分布を大きく超える。val で選んだクラスタが test でもそのまま最悪になる。**

   | 群 | test の最悪 FPR | 帰無分布の 95% 点 | val で選んだ群の test FPR |
   |---|---|---|---|
   | 8 群（年齢 65 歳 × race） | 0.363 | 0.284 | 0.322 |
   | c、K = 4 | 0.421 | 0.261 | 0.421 |
   | ΔW（和）、K = 4 | 0.465 | 0.266 | 0.465 |
   | c、K = 8 | 0.507 | 0.272 | 0.507 |
   | ΔW（和）、K = 8 | 0.497 | 0.276 | 0.496 |

   全体の FPR は 3 seed 平均で 0.246。

4. **クラスタの FPR は、クラスタの陽性率（No Finding の割合）とほぼ一直線に並ぶ。** K = 4 のクラスタで、陽性率と FPR の相関は c 0.91、ΔW 0.91〜0.94、8 群 0.84。最悪 FPR のクラスタは陽性率 0.16〜0.26（全体 0.10）で、TPR も 0.93〜0.95 と高い。逆に AUROC が最悪のクラスタは陽性率 0.04〜0.06 の高齢の群で、FPR は低く TPR は 0.45〜0.72 と低い。

5. **最悪 FPR のクラスタは「若い・PA または側面・女性」の束である。** K = 4 の val で最悪のクラスタは、陰性全体と比べて次の割合だった（3 seed の比の平均）。
   - 多い：PA 撮影 2.3〜3.2 倍、側面像 2.2〜3.4 倍、65 歳未満 1.8〜1.9 倍、女性 1.2〜1.35 倍
   - 多い：正常を明言するレポート（affirmed_normal）1.8〜2.3 倍
   - 病種で多い：Pleural Other 1.8〜2.3 倍、Lung Lesion 1.4〜1.7 倍、Pneumonia 1.4〜1.8 倍
   - 少ない：浮腫 0.4〜0.6 倍、ペースメーカー 0.56〜0.64 倍、デバイス 0.67〜0.85 倍、胸水 0.72〜0.83 倍

   seed 42 の ΔW のクラスタでは、年齢の中央値 48、女性 61%、Black 35%、側面 39%、PA 35%、陽性率 0.216、FPR 0.49。
   ここで PA は `ap_pa = 1`（外来の立位撮影）。test の No Finding の割合は、AP 0.07、PA 0.19、側面 0.17 である。

6. **クラスタの FPR の違いは、モデル入力の属性の構成でほぼ説明できる。病種・文脈の構成だけでは半分ほどしか説明できない。** 見落とし数の O/E の SD（K = 4、層の中の全体 FPR を期待値にする）は次のとおり。

   | 層 | c | ΔW（和） |
   |---|---|---|
   | なし | 0.398 | 0.404 |
   | 8 群（年齢 65 歳 × race） | 0.279 | 0.253 |
   | モデル入力（年齢 65 歳・性別・race・正面側面・AP/PA） | 0.054 | 0.073 |
   | 病種（主要 5 種）・デバイス・胸骨切開・レポート種別 | 0.232 | 0.233 |
   | 両方 | 0.030 | 0.056 |

7. **seed をまたいだ一致は中程度である。** test の ARI は K = 4 で c 0.38、ΔW（和）0.50、K = 8 で 0.45・0.47。K = 2 では c 0.54、ΔW の stage3・stage4・和 0.67〜0.69、fc だけは 0.08 だった。

## 解釈候補

- **推論 1（見つかる群は属性の組み合わせの束ね直し）は、この設定ではそのとおりだった。** クラスタの FPR の違いはモデル入力の属性の構成で SD が 8 割以上小さくなる（観察 6）。これは定義から当然でもある。c も ΔW も属性だけの関数なので、群に意味があるとすれば、「どの組み合わせを束ねるか」をモデルが決めた点だけになる。8 群より悪い群が見つかるのは、8 群が撮影の向き（AP/PA/側面）と性別を使っていないからである。
- **推論 2（ERM の距離は性能の悪さではなく予測の仕方の違い）は、半分当たっている。** クラスタは陽性率の違う群を分けている（観察 4）。ただし、しきい値を固定した FPR では、陽性率の高い群ほど得点が全体に上がり、陰性も「所見なし」と出やすくなる。つまり「予測の仕方の違い」と「見落としの多さ」が、動作点を通して一致してしまう。research-premises の言う「しきい値（動作点）がずれただけ」の差を、そのまま拾っている可能性が高い。
- **最悪群の中身は、外来の若い患者の、微妙な所見（Pleural Other・Lung Lesion・Pneumonia）と、正常を明言するレポートの陰性に寄っている。** 浮腫・胸水・デバイスのような入院の重い所見は少ない。見落としは「ラベルの付き方があいまいな陰性」に集中しているかもしれない。

## 追加で確かめること

- 得点（動作点）をそろえたあとにもクラスタのずれが残るか。陽性率で得点が上がること自体は較正の問題ではないので、較正の O/E で見る（[03 notebook](../03_calibration_bias.ipynb)）。
- 正常を明言するレポートの陰性は、ラベルの誤り（CheXbert の付け方）とどれだけ重なるか。重なるなら、見落としの一部は評価の側の問題になる。
- 他の seed・他のデータ（HAM10000・FairVLMed）で同じ束ね方が出るか。今回は seed 間の ARI が中程度で、束ね方の細部は seed による。
