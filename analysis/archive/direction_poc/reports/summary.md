# 次の方向 5 案の PoC：結果と示唆（2026-10-12）

5 案すべてを、凍結特徴と既存の予測だけで当たり付けした（新しい学習 run は回していない）。詳細は各報告にある。

## 結論

**振り分け（hypernet）を主役にする筋は、5 案のどれでも実データで立たなかった。一方、方向 5 は 1 日で論文の柱になる結果が出た。**
- 実データには、群を使わない MLP に勝つ「規則の食い違い」が見つからない（方向 2・3）。
- 学習時だけの情報を区分にしても効かない（方向 1）。
- 先行手法（Multiaccuracy-Boost）との差分もない（方向 4）。
- 方向 5 では、CheXpert の年齢差のうち順位の差の大半が、ラベルの意味の違いで説明できた。
- 方向 3 の「候補区分を val の利得で選ぶ」方法は、植え込みの場で境界を回収できた。「振り分けが効く場か」を判定する関門として使える。

## 各方向の要点

### 1. 学習時だけの情報で振り分ける（[d1_privileged.md](d1_privileged.md)）

- CheXpert：レポート種別の推定は悪くない（affirmed_normal の判別 AUROC 0.85）。それでも推定で振り分けた頭は global と ±0.001 以内で、GMM 3・ランダム 3 と区別できない。
  学習時に本当の種別、推論時に推定を使う LUPI 型も同じ。非画像の条件（過去検査の有無）も効かない。
- HAM：病理確定かどうかで振り分けると +0.011 [−0.001, +0.022]。ただし MLP（+0.010）や GMM 2（+0.009）と同じ大きさ。
- 推定した条件は画像の関数なので、条件 (i) は満たせない。帰納バイアスとしての効果も、凍結特徴では見えない。

### 2. アーチファクトで規則の食い違いを測る（[d2_artifact_rules.md](d2_artifact_rules.md)）

- アーチファクトは画像処理で推定した：暗い四隅 6.5%、毛 9.9%、明るい背景 4.7%。目視で確認済み。暗い四隅は vidir_modern に集中し、悪性率とも相関する。
- 群ごとの傾きは切片だけの頭に勝たず、MLP には有意に負ける。施設とアーチファクト × 施設でも、MLP との差は区間が 0 をまたぐ。
- 新しい物差しとして、得点を固定して label ~ score + artifact を群ごとに当てる方法を作った。
  - 植え込みの反転は A +3.75 対 B −5.20 で検出できる。フラグを 20% 入れ替えても検出できる。
  - 実データでは |係数| ≤ 1.2 で、反転する組はない。

### 3. 区分を境界に合わせる（[d3_learned_partition.md](d3_learned_partition.md)）

- 凍結特徴でも、正解の区分なら少数側 B の AUROC が +0.251 上がる（上限の目安）。
- search：ラベルを使わない候補区分 35 個を作り、同じ K のランダム区分に対する val の損失の減りで 1 つ選ぶ。
  - 3 seed とも正解を選んだ。
  - 正解を候補から外しても、B を 66% 覆う区分を選び、B を +0.14〜+0.16 戻した。
  - 選ばれる区分は 1 段目の seed によらない。
- MoE（区分と補正の同時学習）：K=2 で B +0.136。ただし B との ARI は 0.17〜0.60、seed 間の ARI は 0.21 で不安定。振り分けの入力に h を入れると効かない。
- 実データ：どの区分も val の損失で定数に負ける。全体 AUROC は −0.008〜−0.013。

### 4. Multiaccuracy-Boost との比較（[d4_multiaccuracy.md](d4_multiaccuracy.md)）

- Q1 設定（a_s42・a_s43、8 群・4 指標）：最悪群 AUROC は MA-Boost 0.757、振り分け r4 0.751。差の区間は 0 をまたぎ、seed で順位が入れ替わる。
- 全体 AUROC の +0.007 は、e（RAD-DINO）を入力に入れた手法に共通して出る。振り分けの構造からではない。
- 植え込み：振り分けが区間で勝ったのはペースメーカーだけ（+0.014）。それも木の監査器とは区別できない。
- 読み出し：マーカーは全体補正でも 1.00 になる。ペースメーカーは木の監査器 0.69 で、振り分け 0.61 を上回る。
- 振り分けは補正の seed による揺れも大きい。

### 5. ラベルの意味の違い（[d5_label_semantics.md](d5_label_semantics.md)）

- 陽性を affirmed_normal に絞ると、次のようになる。
  - 年齢差：−0.052 [−0.084, −0.020]
  - 最悪群：+0.121 [+0.033, +0.224]
  - AUROC gap：半減
  - 6 条件（ResNet・Spatial LoRA・HyperAdapt、ERM・DRO）の違いは消える。
- 分解（厳密な Oaxaca 型）：陽性の種別構成の違いが 1/3（0.023）。同じ追跡撮影型の中の差が 1/2（0.030）。
- しきい値の差は残る。モデルは高齢者の得点を陽性・陰性とも一様に下げる（基底率の写し）。ラベルの意味をそろえても TPR は 0.97 対 0.78。

## 示唆

1. **「hypernet の振り分けが効く条件」の主張は、実データの裏付けがないまま止まっている。** 正の対照では効くが、HAM・FairVLMed・CheXpert のどこにも、
   MLP に勝つ規則の食い違いがない。先行手法との差分（方向 4）もない。振り分けを手法の中心にした論文は勧めない。
2. **方向 5 を主軸にするのが最も筋がよい。** 「属性間の性能差を、ラベル付けの過程（構成と、同じ型の中の差）と、動作点（基底率）に分解する」という問題設定の論文になる。
   - 既存の予測だけで、手法を問わず同じ構造が出る。
   - Q1（部分群の定義で見える差が変わる）の続きとしても自然につながる。
   - 次の作業：
     - 正規表現の分類の妥当性確認（少数の読影確認、または LLM による分類との一致）
     - 陰性側（所見の構成）の分解
     - MIMIC-CXR など別データでの再現
3. **hypernet の役割は「動作点の条件付け」と「場の判定」に絞れる。**
   - 方向 5 で残ったしきい値の差は、群ごとの切片の問題である。属性で条件付ける正当な使い道になる（重みの補正は要らない）。
   - 方向 2 の係数の物差しと、方向 3 の「val でランダム区分に勝つ区分があるか」は、新しいデータで振り分けを試す前の関門として使える。
4. **方向 3 の search を続けるなら、課題は候補の作り方に移る。** 今回の候補は B に有利な作り方（同じ GMM の族）だった。
   複数の埋め込み・メタデータ・レポート由来の区分に候補を広げ、多重比較を抑えた選び方を作る必要がある。

## 共通の限界

- すべて凍結特徴の上の head か、既存の予測の再評価。E2E で区分を教えたときに表現の学び方が変わる可能性は試していない。
- 1 段目の seed は 1〜3 本で、seed は同じ test を共有する（独立な再現ではない）。
- アーチファクト（方向 2）とレポート種別（方向 1・5）は、どちらもヒューリスティクスによる推定である。
