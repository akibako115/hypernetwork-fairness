# 方向 1：学習時にしか無い情報で部分群を作り、推論時は画像から推定して振り分ける（2026-10-12）

`d1_privileged.py`、結果は `results/d1/`。

## 結論

**学習時だけの情報で作った区分は、推論時に画像から推定して振り分けると、同じ数の GMM 区分・ランダム区分・群を使わない MLP と区別できなかった。**
「正しい区分を学習時に教えれば帰納バイアスとして効く」という期待は、凍結特徴の上では支持されない。
本当の区分を test でも使えば効くが、その利得は区分がラベルと重なることによる漏れで説明できる。

- CheXpert（レポート種別、3 区分）：
  - test でも本当の種別を使うと、全体 AUROC が +0.006〜+0.008 上がる（2 seed とも区間は 0 を含まない）。
    affirmed_normal の陽性で測った AUROC は 0.929 から 0.967 に跳ねる。種別は陽性率が 6.6% と 40% で違い、ラベルの手がかりになる。
  - 推定した種別で振り分けると、全体 AUROC の差は −0.003〜+0.001 にとどまる。最悪群・年齢差もほぼ動かない。
    学習時に本当の種別、推論時に推定の事後確率を使う LUPI 型（`lupi_soft`）も、global との差は ±0.001 以内だった。
  - 推定の質は低くない。affirmed_normal の判別 AUROC は 0.85、正解率は 0.74。
  - 全員を「正常を明言した文脈」で読む版（`lupi_std`）は、全体を −0.005〜−0.007 下げる。
  - 推論時にも使えて画像からは計算できない「過去検査の有無」も、差は +0.000〜+0.001 で区間は 0 をまたぐ。
- HAM10000（診断の確定方法：病理か、それ以外か）：
  - 悪性はすべて病理なので、本当の区分を test で使うと全体 AUROC が +0.044 上がる。ほぼラベルそのものである。
  - 推定した区分で振り分ける最良の版（`pred_soft`）は +0.011 [−0.001, +0.022] で、群を使わない MLP（+0.010）と同じ大きさだった。
  - 同じ 2 区分の GMM でも +0.009 [+0.003, +0.014] 出る。学習時だけの区分である必要はない。

## 何を比べたか

- 特徴：CheXpert は Q1 の 1 段目 `a_s42`・`a_s43` の h（train_b で学習し、test で評価）。HAM10000 は DINOv2。
  どちらも標準化して PCA 64 次元に落とした z を使う。
- 頭：すべて z の上のロジスティック回帰。区分で切り替える頭は「切片＋群ごとの重みの差」を持つ。
  - global：z だけ。mlp：z だけの 2 層 MLP（群を使わない非線形の対照）
  - oracle：学習時も test でも本当の区分（test では手に入らない情報を使う参考値）
  - pred / pred_soft：区分を z から推定し（学習側は患者単位 5 分割の cross-fit）、学習時も test でも推定値で切り替える（ハード / 事後確率）
  - lupi_soft / lupi_hard：学習時は本当の区分で頭を学び、test では推定値で切り替える
  - lupi_std：学習時は本当の区分、test では全員を affirmed_normal として読む（ラベル付けの過程を学習時に吸収させる案）
  - 対照：同じ数の GMM（RAD-DINO・DINOv2）、ランダム区分、推論時にも使える非画像の条件（過去検査）、属性
- 区間は test の患者（病変）単位 bootstrap 300 回、global との対応のある差。

## 示唆

- **学習時だけの情報を区分として教えても、推論時に画像から推定する限り、条件 (i)「画像にない情報」は満たせない。**
  凍結特徴の上では、帰納バイアスとしての効果も見えなかった。
- 学習時だけの情報が効く経路は、区分ではなく「ラベルの意味を直すこと」のほうにある。CheXpert では、方向 5 の結果（affirmed_normal の陽性で順位の年齢差が消える）がそれにあたる。
  ラベル付けの文脈で条件付けて推論時に標準の文脈で読む案（`lupi_std`）は、凍結特徴では悪化した。
- 推論時にも使えて画像から計算できない情報（過去検査の有無）も、凍結特徴の上では使われなかった。
  ただし、これは「画像の特徴の上の切り替え」で測ったもので、過去検査の画像そのものを入れる構成は試していない。
- 方向 1 を E2E で試す意味は小さい。方向 2・3 で「規則が食い違う区分」が見つかったときに、その区分の推定器として使うのが筋になる。

## 限界

- 凍結特徴の上の head だけで、backbone ごと学習する構成（E2E の hypernet）は回していない。E2E では、区分の教示が表現の学び方を変える可能性は残る。
- レポート種別は正規表現の分類。HAM の確定方法はラベルとほぼ一致するので、区分としては極端な例になる。
- CheXpert は 1 段目の seed 2 本、HAM は特徴 1 種類で、頭の seed は 1 つ（MLP だけ 3 seed の平均）。
