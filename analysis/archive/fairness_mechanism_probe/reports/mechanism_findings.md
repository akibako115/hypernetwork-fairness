# 属性で条件付けても縮まらない差の正体：CheXpert No Finding の機構診断（2026-10-06）

## 結論

**このタスクでは、ERM の固定特徴の上で属性ごとに判定規則を変えても、群内の順位（AUROC）を改善する余地が見つからなかった。**
backbone ごと条件付けた学習は既存 run の比較しかなく、hypernetwork 全般が不向きとまでは言えない。
8群（年齢2区分×race 4区分）の差を分解すると、大半は次の2つで説明できる。

1. **基底率による動作点のずれ**：共通閾値で生じる。モデルは群内で較正されている。
2. **「No Finding」ラベルの意味の揺れ**：年齢とともに中身が変わる。

race による差はほぼ無い。
属性別の決定境界・高齢群への特化・公平性損失・属性の消去は、いずれも群内の順位（AUROC）を改善しなかった。

数字で言うと次のとおり。

- クラス内 margin の分散のうち、race で説明できるのは 0.1%、年齢10歳刻みは陽性側で 25%。
- 全体で1回だけ再較正すると、8群すべてで平均予測確率が実際の陽性率と一致する（差は0.01前後）。
  共通閾値の TPR gap 0.47 のうち約半分は、val で決めた群別閾値だけで消える（0.26）。
- レポートが正常を明言した陽性に限ると、AUROC は年齢によらず 0.91〜0.93 で平坦になる。
  年齢差（<50 の 0.865 → 80歳以上 0.744）は、ほぼ「追跡撮影型」の陽性に集中する。
  追跡撮影型とは、デバイス位置や気胸の有無だけに答え、他の所見に触れないレポートを指す。
  同じ傾向が既存9条件（ResNet・Spatial LoRA・HyperAdapt、ERM/DRO、1/2-stage）すべてで再現した。
- 凍結 ERM 特徴の上で群別 head を学習すると、自由度を増やすほど単調に悪化した（3seed）。
  hypernet head（rank 4）は共有 head と同等で、worst +0.003 にとどまった。
  FairVLMed（眼底・緑内障）で同じ診断をすると、群別 head は3seedとも全体 AUROC を上げた（+0.003〜0.006）。
  向きが CheXpert と逆になる点は3seedで一貫するが、効果は小さく、群は小さく、bootstrap は未実施。
- worst-group AUROC の test 標本雑音は、paired bootstrap でも SE 0.010〜0.013。
  既存比較で見えた条件間差（0.005〜0.015）は、この雑音と区別できない。

**次の一手は、手法を足すことより、公平性の定義と課題の選び方を見直すことにある。**
具体的な提案は[最後の節](#研究の方向性への示唆)にまとめた。

## 前提と範囲

- 対象：CheXpert の No Finding 2値分類。陽性＝所見なし、陽性率は train 10.3%。
  split は `splits_race_known`（test 19,617件）、群は学習側の DRO と同じ8群。
- モデル：主に M01（ResNet-50 ERM、global inverse class weight）の 3seed で、best val AUROC checkpoint。
  凍結特徴は分類 head 直前の2048次元（`features.py`）。
- 既存の主比較9条件の予測は `race_known_architecture_objective_comparison/cache/` を読み取り専用で使った。
- レポート文は CheXpert Plus の `section_impression`。
  種別は正規表現による分類（`label_construct.py`）で、レポートの書かれ方を分けたものにすぎず、臨床的な正誤は判定していない。
- fine-tune probe（`probes/train_probe.py`）は run 契約の外で回した当たり付け。seed 42 の1本ずつしかない。

## 1. 差の大半は年齢の連続的な勾配で、race はほぼ寄与しない

M01 の AUROC は年齢とともに単調に下がる。
30代 0.868、60–64歳 0.821、70代 0.790、80歳以上 0.716 である（seed 42）。
8群の「≥65」側が悪いのは、この勾配を65歳で切った結果である。

誤りの不均一さを、クラス内の符号付き margin（陽性は s、陰性は −s）の分散分解 η² で比べた（`latent_groups.py`）。

| 分割 | η²（陽性） | η²（陰性） |
| --- | ---: | ---: |
| race 4区分 | 0.001 | 0.003 |
| sex | 0.001 | 0.000 |
| 年齢 65歳で2区分 | 0.162 | 0.039 |
| 年齢 10歳刻み | 0.254 | 0.068 |
| 人口統計8群 | 0.173 | 0.041 |
| 正面/側面 | 0.042 | 0.064 |
| 保険種別 | 0.086 | 0.030 |

8群が捉えている不均一さは、ほぼ年齢の分だけである。
最悪群 ≥65×Others（陽性68件）の AUROC 0.737 は、患者単位 bootstrap の 95% 区間が 0.65〜0.82 と広い。
≥65×White との差 −0.079 も区間 [−0.17, +0.01] で、0 を含む。
race の効果というより、少数標本のゆらぎと年齢構成の影響と読むのが妥当と考える。

k-means（表現空間）の η² は 0.8〜0.97 になったが、これは使えない。
表現がスコアを決めるため、クラスタはスコアの層とほぼ一致してしまう。
潜在サブグループを表現から切る場合は、課題と独立な表現を使うか、スコア方向を除く必要がある。

## 2. EO の差は基底率の差から必然的に生じている

高齢群では陽性スコアが全体に低い側へずれる（陽性の平均 margin：<65×White 1.50、≥65×White 0.18）。
共通閾値0では、高齢群の TPR が低く（0.44〜0.79）、若年群の TNR が低い（0.66〜0.72）。

このずれはモデルの誤りではない。val で全体に1回だけ Platt 再較正すると、8群の平均予測確率は観測陽性率と一致する。
たとえば ≥65×White は 0.060 対 0.058、<65×Asian は 0.150 対 0.160 である（3seed 平均、`operating_point.py`）。
群内で較正されたモデルに異なる基底率が重なれば、共通閾値の EO は満たせない。
これは Kleinberg ら・Chouldechova の不可能性定理が述べる状況そのものである。

閾値を群ごとに val で決めると（M01 3seed、test で評価）、次のようになった。

| 方針 | Eopp1 | Eopp0 | worst BACC | 群平均 BACC |
| --- | ---: | ---: | ---: | ---: |
| 共通閾値0 | 0.473 | 0.210 | 0.654 | 0.758 |
| 群別 Youden | 0.294 | 0.216 | 0.690 | 0.759 |
| 群別に TPR をそろえる | 0.262 | 0.320 | 0.671 | 0.750 |

TPR をそろえると Eopp0 が広がる。どちらの誤りを揃えるかは、学習ではなく規範の選択である。

群別閾値のあとにも TPR の差は 0.22〜0.31（seed 別）残る。2b節で分けたとおり、これは主に少数群の標本雑音による。
仮に全群の真の TPR が等しくても、test の陽性数（22〜823件）による標本誤差だけで差は平均 0.12〜0.13、95% 点で 0.21〜0.23 出る。
観測値はこれを上回るが、閾値を決める val 側の雑音を加えると説明できる範囲に入る（2b節）。
陽性150件以上の4群に限っても差は約 0.10 残る。
小さい群では val の陽性が34〜69件しかなく閾値の推定自体が不安定なこと、患者内の画像相関で実効標本数が小さいことも効くが、
分け直しによる分解は2b節に置く。
この課題で陽性と判定することは「正常なので後回しにする」ことを意味するので、害が大きいのは偽陽性（所見の見逃し）のほうだ。
その意味で最も不利なのは、TNR が低い若年群である。
さらに、デバイスなしの若年の TNR は 0.585 まで下がる（デバイスありの若年は 0.794）。
これは Seyyed-Kalantari ら（Nature Medicine 2021）の underdiagnosis の議論と同じ向きである。
現行の主指標 worst AUROC と、Eopp1 を中心にした読み方は、この害の向きと一致していない。

## 2b. 群別閾値のあとに残る TPR 差は、少数群の標本雑音でほぼ説明できる

`residual_tpr_gap.py`。M01 のスコアは固定し、閾値の決め方だけを比べた。
val ∪ test を患者単位で半分ずつに分け直し（校正側で閾値を決め、評価側で測る）、3seed × 200回繰り返した。

**残差は分け方の偶然の範囲に入る。** 元の val→test で群別閾値の TPR 差は 0.262 / 0.218 / 0.306（seed 42/43/44）。
これは分け直し分布の 73 / 62 / 86 パーセンタイルにあたる。分け直しの平均では、群別閾値で8群の TPR は 0.79〜0.82 にそろう。
1回ごとに差が出るのは、小さい群（陽性 22〜69件）で閾値の推定と TPR の評価の両方がぶれるためである。
前に「≥65×Others が3seedとも最小」と書いたが、3seed は同じ val/test の患者を使うので、独立な再現ではなかった。
分け直しでは最小の群は毎回入れ替わる（≥65×Black 32%、≥65×Others 20%、≥65×Asian 18% など）。

**群の間で情報を共有すると、差は少し縮む。** 同じ分け方の上で、群ごとに独立した閾値と比べた。

| 閾値の決め方 | TPR 差（分け直し平均） | 独立閾値との差（95%範囲） | 独立閾値より小さい割合 | worst TNR |
| --- | ---: | --- | ---: | ---: |
| 共通（argmax） | 0.402 | — | — | 0.673 |
| 群ごとに独立 | 0.214 | — | — | 0.516 |
| 加法モデル（年齢2区分＋race）の分位点回帰 | 0.171 | −0.043（−0.237〜+0.081） | 67% | 0.517 |
| 独立と加法の縮小推定 | 0.174 | −0.040（−0.222〜+0.063） | 67% | 0.528 |
| 連続年齢＋race の分位点回帰 | 0.181 | −0.032（−0.237〜+0.131） | 64% | 0.518 |
| 属性→MLP（hypernet 型の条件付き切片） | 0.198 | −0.016（−0.201〜+0.144） | 56% | 0.470 |

雑音だけで出る差（全群の真の TPR が同じと仮定）は平均 0.119 で、加法モデルはそこから 0.05 上まで縮める。
柔軟な MLP は単純な加法モデルに及ばず、TNR の悪化も大きい。小さい群では、柔軟さより情報の共有が効く。
加法モデルは ≥65×Black の TPR を 0.88 と高めに外す（交互作用を持たない偏り）ので、ばらつきと偏りの交換である。

**本当の代償は TNR 側に出る。** TPR を全群 0.82 前後にそろえると、高齢群の TNR は 0.83〜0.86 から 0.57〜0.68 に下がる。
高齢群では所見のある患者を「所見なし」とする見逃しが増えるということで、これは高齢群の AUROC が低いことの直接の帰結である。
TPR 差そのものは閾値の推定の問題に帰着し、解くべき問題は群内の判別力の差（3節）に戻る。

## 3. 年齢差の正体は「No Finding」ラベルの意味の揺れ

ここが今回の中心の発見である。

陽性のレポートを3種に分けた（`label_construct.py`）。
「affirmed_normal」は「no acute cardiopulmonary」などで正常を明言したもの、
「focused_followup」はデバイス・気胸・前回比較など特定の問いに答えるだけのものである。
高齢になるほど focused_followup が増え（若年 43% → 高齢 58%）、affirmed_normal が減る（45% → 28%）。

陰性はすべて残し、陽性だけを種別で絞って AUROC を求めた（M01 3seed の logit 平均）。

| 年齢帯 | 陽性全体 | affirmed_normal | focused_followup |
| --- | ---: | ---: | ---: |
| <50 | 0.865 | 0.911 | 0.809 |
| 50–64 | 0.863 | 0.925 | 0.797 |
| 65–79 | 0.824 | 0.908 | 0.778 |
| 80+ | 0.744 | 0.915 | 0.671 |

**正常と明言された胸部なら、モデルは80歳以上でも若年と同じ精度で見分けている。**
差は、レポートが他の所見に触れていない追跡撮影の陽性に集中する。
高齢の陽性のうちスコアが最も低い12件のレポートを読むと、ICU での中心静脈カテーテル留置確認やチューブ抜去後の「気胸なし」が並んだ。
これは上位12件の事例で、高齢の陽性全体の傾向ではない。デバイスに触れるレポートの割合は、陽性では若年・高齢とも35〜44%でほぼ同じだった。
「画像は正常ではなく、レポートが触れていないだけ」というのは推測で、読影医による確認はしていない。
また、正常を明言された陽性は典型的な正常画像が選ばれやすく、その AUROC が高いこと自体は選択の効果を含みうる。
陰性側も同様で、所見の種類（胸水・無気肺・心拡大など）の構成は年齢でほぼ変わらない。
それでも、所見ごとの AUROC は高齢で一律に 0.06〜0.08 下がる。

既存9条件でも構造は同じだった。
affirmed_normal の年齢差は 0.010〜0.017、focused_followup の年齢差は 0.05〜0.06 である。
DRO は focused_followup の高齢を下げている（M01 0.754 → M02 0.741、Spatial DRO 0.740）。
hypernet 系 ERM はわずかに高い（M03 0.766、M07 0.759）が、雑音の範囲を出ない。

過去検査の有無（`patient_report_date_order>1`）は推論時にも得られる文脈で、これとも対応する。
AUROC は追跡撮影の高齢で 0.777、初回撮影の高齢で 0.831、追跡撮影の若年で 0.874 だった。

解釈：高齢群の低い AUROC は、画像を見分ける力の不足よりも、目標ラベルの意味が群ごとに違っていることに由来する。
「公平に予測する」対象が、群によって別物になっている。

## 4. 属性ごとの最適な処理には伸びしろが見つからない

### 凍結特徴の上の条件付け

条件付けの形だけを変えた head を train で学習し、val AUROC で epoch を選んだ（`heads.py`、M01 3seed）。
数値は共有 linear head との差の平均である。

| head | 全体 | ≥65×White | ≥65×Others | 群平均 |
| --- | ---: | ---: | ---: | ---: |
| 群別切片のみ | −0.0002 | +0.0001 | −0.0021 | −0.0004 |
| 共有＋群別Δw（L2 1e-1） | −0.0032 | −0.0015 | −0.0068 | −0.0062 |
| 共有＋群別Δw（L2 1e-3） | −0.0043 | −0.0023 | −0.0124 | −0.0120 |
| 群ごとに独立 | −0.0046 | −0.0037 | −0.0157 | −0.0149 |
| 年齢との連続交互作用 | −0.0015 | −0.0024 | −0.0046 | −0.0037 |
| hypernet（属性→rank 4 のΔw） | +0.0001 | +0.0011 | +0.0031 | +0.0008 |
| MLP（属性入力あり） | −0.0007 | −0.0016 | −0.0047 | −0.0010 |

群ごとの自由度を増やすほど単調に悪くなる。
test 6,326件の ≥65×White でも改善しないので、少数群の過学習だけでは説明できない。
ERM 特徴の上では、共有の決定規則がすでに群ごとの最適にほぼ一致している。
撮影文脈（年齢×初回/追跡の4セル）で条件付けても同じだった（`context_heads.py`、hypernet で +0.001〜0.003）。

### 表現を群に特化させる

M01 から高齢データ（70,322件）だけで fine-tune した specialist を作った。
val の高齢 AUROC は最大 0.817 で、M01 の 0.824 を下回った。
test では specialist 0.798、同予算の全データ継続学習 0.796、M01 0.792 で、差はわずかだった（seed 42 の1本ずつ）。
ImageNet から群別に学習する比較は[付記](#付記imagenet-初期化の群別学習)に置く。

### ラベル生成過程で条件付ける

学習時だけレポート文脈（focused_followup か）で切片・Δw を条件付け、推論時はその項を外して読んだ（`label_process_heads.py`）。
文脈の吸収で共有部分が「画像の正常さ」に近づくなら、高齢群が上がるはずだった。
結果は高齢 0.8028 → 0.8028〜0.8035 で、変化しなかった。
凍結特徴の範囲では、追跡撮影型の陽性を画像から見分ける情報が足りない。
そうした画像は実際に異常を含み、レポートが触れていないだけという解釈と矛盾しない。

## 5. 明示的な公平性損失と属性の消去は順位を動かさない

共有 linear head に固定し、目的関数だけを変えた（`objectives_frozen.py`、3seed 平均）。

| 目的関数 | 全体 | 高齢 | 若年 | worst |
| --- | ---: | ---: | ---: | ---: |
| ERM | 0.8644 | 0.8028 | 0.8708 | 0.7344 |
| 群均等 | 0.8640 | 0.8032 | 0.8702 | 0.7348 |
| Group DRO | 0.8640 | 0.8021 | 0.8704 | 0.7324 |
| 群内 worst-rank 損失 λ=1 | 0.8641 | 0.8047 | 0.8698 | 0.7382 |

差はすべて ±0.004 以内で、標本雑音（worst の SE 約0.01）を大きく下回る。
表現を固定すると、損失の選び方で群内順位はほぼ変わらない。

LEACE で属性の線形情報を表現から消し、head を学習し直した（`erasure.py`）。
年齢を消すと、高齢−若年の TPR 差は 0.26 → 0.18 に縮む。
しかしこれは高齢の TNR が 0.84 → 0.79 に下がった結果で、AUROC は高齢で 0.016、若年で 0.008 下がった。
加えて、非線形 probe では年齢がほぼ残る（R² 0.48 → 0.45）。
差が縮んだように見えるのは全員の性能を下げて揃えた結果で、いわゆる leveling down にあたる。
Zhang ら（CHIL 2022）が CXR で報告した傾向と一致する。

## 6. Hypernetwork をバイアス解析に使うなら、属性の通り道は2本ある

M01 の表現は属性を強く符号化している（val で probe を学習し test で評価）。
年齢は R² 0.50（MAE 10歳）、sex は AUROC 0.95、撮影方向は 1.0、AP/PA は 0.99、race は 0.63〜0.75 だった。
陽性のスコアは、実年齢（相関 −0.49）より画像から推定した年齢（相関 −0.66）とよく対応する。

元の分類器を固定し、表現から年齢の部分空間だけを LEACE で除いて logit の変化を見た（3seed 平均）。
画像に符号化された年齢は、若年群の logit を +0.36〜0.50、高齢群を −0.45〜0.52 動かしている。
race の部分空間も <65×Black・Others を +0.31〜0.34 動かす。
ただし race は誤りの分散をほとんど説明しないので、基底率を写す事前確率として働いていると読める。

hypernet に属性を metadata として渡す経路は、この「画像経由の属性」とは別の、2本目の経路である。
既存の反実仮想 metadata 解析（M06 best で race 差し替えの判定反転 2.1%）が測れるのは、2本目の依存だけだ。
モデルが属性を使っている量の全体は、2つの経路を分けて測る必要がある。
1本目の経路は今回のような概念消去で、2本目は metadata の反実仮想で測れる。

## 7. 評価の雑音：worst-of-8 は 0.02 未満の差を判定できない

既存の主比較ペアで、患者単位 paired bootstrap の SE を出した（`paired_noise.py`、3seed の logit 平均どうし）。

| セル | SE の範囲（4ペア） |
| --- | --- |
| <65×White | 0.0015〜0.0020 |
| ≥65×White | 0.0023〜0.0046 |
| ≥65×Others | 0.0086〜0.0122 |
| ≥65×Black（陽性22件） | 0.014〜0.024 |
| worst-of-8 | 0.0094〜0.0127 |

3seed の標準偏差は同じ test 集合での学習のばらつきで、この標本雑音を含まない。
worst-of-8 で差を主張するには、およそ 0.02〜0.025 以上が要る。
年齢の連続曲線やレポート種別で層別した AUROC のほうが、同じ test でずっと精度よく比べられる。

## 研究の方向性への示唆

### 公平性を「何を予測すべきか」から定義し直す

今回の課題で最大の群間差は、群ごとにラベルの意味が違うことから来ていた。
この状況でラベルとの一致を群間で揃えると、レポートの書き方の偏りを再現するだけになる。
**目標は画像に写っている状態とし、評価はラベルの意味が揃った部分集合で行う**ことを提案する。
affirmed_normal 陽性による評価や、所見別の陰性による層別 AUROC がその例である。
CheXpert Plus の impression を使えば、既存 run の再評価だけで今すぐ始められる。

### 誤りの害の向きを先に決め、動作点は学習と切り離す

EO の差の半分は群別閾値で消え、残りもモデルが較正された結果である。
どの誤り率を群間で揃えるかは、学習を始める前に規範として決めておく事項である。
No Finding をトリアージに使うなら、見逃し（FPR）の群間差を主指標に据えるのが筋である。
その場合に最も不利なのは、デバイスのない若年の外来患者になる。
群別の動作点は群別の切片1つで実現できる。ただし群別閾値のあとも TPR 差は残り、小さい群では閾値の推定が不安定になる。属性から動作点を群間で共有しつつ決めるモデル（hypernet 型を含む）がこれを安定させるかは、未検証の仮説である。
属性を判断に明示的に使うことの是非（disparate treatment）は、別に議論が要る。

### hypernetwork を試すなら「属性と画像の交互作用」がありそうな課題で

凍結特徴での head 実験は数分で済み、属性別の処理に伸びしろがあるかを判定できる。
**新しい課題やデータセットでは、モデルを作る前にこの診断を関門として通す**ことを勧める。
共有 head と群別 head の差、hypernet head の差、自由度に対する単調性を見ればよい。
候補は HAM10000（肌色によって病変の見え方が変わる）や FairVLMed で、交互作用が期待できる。
CheXpert No Finding では、属性ごとの最適な処理という仮説は支持されなかった。

FairVLMed（SLO 眼底・緑内障、train 7,000件）で同じ診断を試した（`probes/fairvlmed_headroom.py`）。
ImageNet から ERM で学習し、race 3区分×年齢2区分の6群で head を比べた。共有 head との差は次のとおり。

| head | 全体 AUROC の差（seed 42 / 43 / 44） | 群平均 AUROC の差（3seed 平均） |
| --- | --- | ---: |
| 共有＋群別Δw（L2 1e-1） | +0.0043 / +0.0030 / +0.0044 | −0.0014 |
| 群ごとに独立 | +0.0002 / +0.0057 / +0.0062 | −0.0010 |
| hypernet（rank 4） | +0.0036 / +0.0035 / +0.0042 | +0.0040（3seed とも正） |

同じ head 群の、CheXpert での全体 AUROC の差は次のとおり。

| head | 全体 AUROC の差（seed 42 / 43 / 44） |
| --- | --- |
| 共有＋群別Δw（L2 1e-1） | −0.0033 / −0.0026 / −0.0037 |
| 群ごとに独立 | −0.0040 / −0.0025 / −0.0072 |
| hypernet（rank 4） | −0.0003 / +0.0006 / −0.0001 |

群別の決定境界の符号が、2つのデータセットで3seedとも逆になった。
FairVLMed には属性と画像の交互作用が小さいながら存在する可能性がある。hypernet head は群平均を3seedとも上げたが（+0.001〜0.007）、worst は seed で符号が変わる（−0.006 / +0.019 / +0.018）。
効果量は小さく、FairVLMed の群は test で 55〜775件しかないので、群別の値は雑音が大きい。
それでも、凍結特徴の診断がデータセットの違いを数分で見分けられることは確認できた。

### hypernetwork の別の使い道は2つ

1つ目は、ラベル生成過程のモデルとしての使い道である。
学習時にラベルの付き方の文脈で条件付け、推論時は標準の文脈で読む。
凍結特徴では効果が出なかったが、表現ごと学習する場合と、文脈がより明確な課題（読影者の違いなど）では未検証である。

2つ目は、監査の道具としての使い道である。
metadata の反実仮想（明示経路）と概念消去（画像経路）を組み合わせ、属性への依存を経路別に定量化する。
今回の集計はその試作になっている。

### 評価の作法

worst-of-8 だけで結論を出さない。患者単位 paired bootstrap の SE を併記し、年齢は連続曲線で示す。
群の数を増やすほど worst は雑音に支配される。

## 限界と未確認

- レポート種別は正規表現の分類で、臨床的な正誤ではない。affirmed_normal の陽性は、画像が典型的に正常で選ばれやすい可能性もある。読影医による再ラベルは無い。
- 凍結特徴は ERM が全データで学習した表現である。属性別の情報を最初から捨てている可能性は残る。specialist fine-tune は seed 42 の1本だけ。
- k-means による潜在サブグループは、スコアとの循環のため結論に使っていない。課題と独立な表現（ImageNet など）での再試行が未実施。
- FairVLMed の診断は ERM 1本ずつ（3seed）の凍結特徴で、群別 AUROC の bootstrap は未実施。HAM10000 は未実施。
- fine-tune probe は run 契約の外にある。結論に使う場合は `hypernet_e2e` の run として回し直す必要がある。

## 付記：ImageNet 初期化の群別学習

学習データの件数を高齢群と同じ 70,322件にそろえ、どの群のデータで学習するかだけを変えた。
ImageNet から10 epoch、seed 42 の1本ずつで、val 全体 AUROC 最大の epoch を test で評価した（`probes/summarize_probes.py`）。

| 学習データ | 全体 | 若年 | 高齢 | ≥65×Others |
| --- | ---: | ---: | ---: | ---: |
| 高齢のみ | 0.844 | 0.845 | 0.793 | 0.735 |
| 全年齢から無作為 | 0.855 | 0.859 | 0.796 | 0.720 |
| 若年のみ | 0.852 | 0.859 | 0.787 | 0.699 |

高齢 test に対しては、どのデータで学習しても 0.787〜0.796 に収まる。
高齢だけで学習しても、無作為の混合データを上回らない。若年だけのデータとの差も 0.006 にとどまる。
逆向きの差は大きく、若年 test に対して高齢だけのデータは 0.014 劣る。
識別に使う構造は年齢をまたいで共有されており、自分の群のデータに特化する利得は見られない。
高齢群の AUROC の低さは、学習データの不足や群の取り違えでなく、高齢 test 症例そのものの難しさ（3節のラベルの揺れを含む）に由来すると考える。

1本ずつの比較で、高齢 AUROC の標本雑音（paired でおよそ 0.005）と同程度の差である。
≥65×Others（陽性68件）の 0.699〜0.735 の差は、7節の SE を考えると読まない。
